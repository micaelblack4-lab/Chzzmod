# ShopCHZ

Mod de loja completo para **Minecraft 26.1.2** (Fabric).

## Economia

Dinheiro **virtual** do shop (não usa item do jogo).

- Todo jogador começa com **$1000**
- Comprar gasta dinheiro
- Vender recebe dinheiro

## Comandos

| Comando | Descrição | Quem |
|---------|-----------|------|
| `/loja` | Abre a loja | Todos |
| `/saldo` ou `/dinheiro` | Ver seu saldo | Todos |
| `/dinheiro dar <jogador> <qtd>` | Dar dinheiro | OP |
| `/dinheiro setar <jogador> <qtd>` | Definir saldo | OP |
| `/dinheiro remover <jogador> <qtd>` | Remover dinheiro | OP |

## Como comprar / vender

1. `/loja` → escolhe a categoria
2. Clique **esquerdo** no item = **Comprar**
3. Clique **direito** no item = **Vender**

Ou por comando:
```
/loja tools comprar 0
/loja tools vender 0
```
